# 오목 · 쿼리도

친구와 함께하는 온라인 보드게임입니다. 방을 만들 때 **렌주 오목**(2인) 또는 **쿼리도**(2~4인)를 고릅니다.

## 쿼리도
- 방장이 2/3/4인 중 인원을 정하고, 인원이 다 차면 자동으로 시작합니다 (남는 사람은 관전).
- 차례마다 말을 한 칸 움직이거나 벽을 하나 놓습니다. 반대편 끝 줄에 먼저 도착하면 승리.
- 벽은 2인 10개, 3인 7개, 4인 5개씩. 누군가의 길을 완전히 막는 벽은 놓을 수 없습니다.
- 3~4인전에서 기권·퇴장·시간 초과한 사람은 말이 빠지고 나머지끼리 계속합니다.
- 무르기는 나머지 대국자 전원이 수락해야 합니다. 재대국 때마다 첫 차례가 바뀝니다.

## 오목 기능
- 방 코드 / 초대 링크로 친구와 대국 (3번째 입장자부터 관전)
- 렌주룰: 흑 3-3·4-4·장목 금수 (흑 차례에 금수 자리 ✕ 표시), 흑 첫 수는 천원
- 체스 시계 방식 제한 시간: 각자 5 / 10 / 20분(기본 10분)을 받고, 자기 차례에만 줄어들며, 다 쓰면 패배
- 무르기(상대 수락 필요), 기권, 재대국(흑백 교대)
- 채팅, 수순 번호 표시, 착수 효과음
- 새로고침·연결 끊김 시 30초 안에 돌아오면 자리 유지

## 내 컴퓨터에서 실행
```
npm install
npm start
```
브라우저에서 http://localhost:3000 접속.
테스트(렌주·쿼리도 규칙, 서버): `npm test`

## 친구와 하기 — Render 무료 배포
1. 이 폴더를 GitHub 저장소에 올립니다 (`node_modules`는 제외됨).
2. https://render.com 가입 → **New + → Web Service** → 저장소 선택
3. 설정
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
4. 배포가 끝나면 나오는 `https://<이름>.onrender.com` 주소로 접속해 방을 만들고, **초대 링크 복사** 버튼으로 친구에게 링크를 보내면 됩니다.

> 무료 플랜은 15분간 접속이 없으면 서버가 잠들어 첫 접속에 30~50초 정도 걸립니다.
> 서버가 재시작되면 진행 중이던 방은 사라집니다.
