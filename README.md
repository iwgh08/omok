# 렌주 오목

친구와 함께하는 렌주룰 온라인 오목입니다.

## 기능
- 방 코드 / 초대 링크로 친구와 대국 (3번째 입장자부터 관전)
- 렌주룰: 흑 3-3·4-4·장목 금수 (흑 차례에 금수 자리 ✕ 표시), 흑 첫 수는 천원
- 한 수당 제한 시간 (15 / 30 / 60초, 초과 시 패배)
- 무르기(상대 수락 필요), 기권, 재대국(흑백 교대)
- 채팅, 수순 번호 표시, 착수 효과음
- 새로고침·연결 끊김 시 30초 안에 돌아오면 자리 유지

## 내 컴퓨터에서 실행
```
npm install
npm start
```
브라우저에서 http://localhost:3000 접속.
렌주 판정 테스트: `npm test`

## 친구와 하기 — Render 무료 배포
1. 이 폴더를 GitHub 저장소에 올립니다 (`node_modules`는 제외됨).
2. https://render.com 가입 → **New + → Web Service** → 저장소 선택
3. 설정
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
4. 배포가 끝나면 나오는 `https://<이름>.onrender.com` 주소로 접속해 방을 만들고, **초대 링크 복사** 버튼으로 친구에게 링크를 보내면 됩니다.

> 무료 플랜은 15분간 접속이 없으면 서버가 잠들어 첫 접속에 30~50초 정도 걸립니다.
> 서버가 재시작되면 진행 중이던 방은 사라집니다.
